# Winget 软件管家 2.18.1（C# WPF 版）— 标题栏按钮重制

这一版只动界面：**标题栏的四个窗口按钮（信息 / 最小化 / 最大化 / 关闭）与搜索框清除按钮全部重画**，功能与 2.18.0 完全一致。

## 改了什么，为什么改

旧版这几个图标是**字体字符**（`ⓘ ─ □ ✕`，最大化后切成 `❐`），用 12.5px 文本渲染。问题不在字号，在「字形不可控」：

- 这五个字符在字体里**大小、粗细、基线参差** —— `─` 细成一根发丝、`ⓘ` 缩成一点、`□` 偏小；
- 形态随系统字体回退漂移，换台机器就不是同一张脸，`❐` 在不少字体里直接**缺字**；
- 小字号 + 抗锯齿，边缘容易发虚。

所以单纯调大字号救不回来。这一版把它们换成**矢量描边图标**：

| 项 | 旧 | 新 |
|---|---|---|
| 图标本体 | 字体字符，实际笔画约 8 DIP | 矢量描边，**15×15 画布，实际笔画约 10.5 DIP** |
| 线宽 | 随字体漂移 | **固定 1.2**，圆角线帽 / 圆角拐角 |
| 按钮热区 | 30×28 | **36×30**，hover 圆角 8，按钮间留 2px 缝 |
| 还原图标 | 字符 `❐`（常缺字） | 前后叠放的圆角双框，与「还原」tooltip 同步切换 |

关键取舍：**图标放大时线宽刻意不跟着放大**。线宽同比放大（1.2 → 1.5）会让图标变粗变笨，精致感来自「大而细」——所以只重排坐标，不动描边。

顺带把「关于 / 导出 / 指南」三个对话框的关闭按钮也换成了同一套矢量字形，全应用不再有一个字体字符图标。

## 功能（与 2.18.0 相同）

- **扫描** `winget list`，按「软件 / 系统组件·运行库」分节展示，支持搜索、分组折叠、批量勾选
- **导出三种格式**（一套三个文件）：
  - `apps.json` —— UTF-8 无 BOM，可直接喂给 `winget import`
  - `恢复-*.bat` —— GBK + CRLF，双击即按清单批量重装（cmd.exe 对编码敏感，这里踩过坑）
  - `无法自动重装清单-*.html` —— 单文件内联 CSS/JS，离线可开，列出 winget 装不回来的东西及手动处理建议
- **元数据异步核查**：本地缓存 TTL 默认 90 天，可用 `WPM_META_TTL_DAYS` 调整（`0` = 永不过期）
- **便携模式默认开启**：数据在 exe 同级 `Data\`（勾选状态 / 缓存 / 日志），目录不可写时自动回退 `%LOCALAPPDATA%\WingetManager`

**定位是只导出、不导入**：本工具不会替你安装任何软件，安装动作只发生在恢复脚本由你亲手双击时。

## 验证

| 项 | 结果 |
|---|---|
| 编译 | **0 error / 0 warning** |
| 自测 | **445 / 445 项断言通过**（本地中文 Windows 与 CI `windows-latest` 双语环境各跑一遍） |
| 静态检查 | BLOCKER=0 / MAJOR=0 / MINOR=39（39 条均为判定「有意保留」的主题令牌与模板内重名 `x:Name`） |
| 实跑截图 | 默认态四枚描边图标粗细一致；关闭按钮 hover 红底白 X；最大化后还原图标呈前后双框、窗口顶边无裁切 |

新增回归锁 **T41**（13 条断言），锁死三件事：五个字形资源必须存在、XAML 里不许再出现 `Content="□"` / `Content="✕"` / `Content="ⓘ"` 这类字体字符写法、最大化与还原的切换必须走 `FindResource("Glyph.Window.Restore" / "...Maximize")`。以后谁改回字体字符，自测会直接红。

本 release 的 exe 由 GitHub Actions 在 `windows-latest` 上构建并直接上传，与本仓库 tag 一一对应，未经手动替换。

## 已知局限

- 便携模式的数据在 `Data\`；若把 exe 单独拷到只读目录（如 `C:\Program Files`），数据会自动落到 `%LOCALAPPDATA%`。
- 纯视觉项（对话框首帧高度、无边框窗口最大化留边、字体回退观感）无法自动化，建议肉眼看一眼。
- 逻辑层未做 fuzz；`winget list` 的输出格式若大改，解析器需跟着调整（已有 `ParseByGaps` 兜底与 445 条断言护着）。
