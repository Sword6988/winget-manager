# Winget 软件管家 2.18.2（C# WPF 版）— Win11 原生风格重设计

这一版是一次**纯视觉重构**：整套界面按 Windows 11 原生设计语言重新调色、收圆角、去渐变，功能、交互与快捷键和 2.18.1 完全一致（445 项自测断言零改动通过）。

## 改了什么，为什么改

v3「清朗 Azure」用了 Tailwind 蓝紫渐变 + 假玻璃拟态，好看但离系统原生感偏远。这一版向 Win11 原生收敛：

| 维度 | 旧（v3 清朗 Azure） | 新（v4 Win11 原生） |
|---|---|---|
| 品牌色 | Tailwind 蓝 #2563EB → 天蓝渐变 | **Win11 系统蓝三阶**：base #0067C0 / hover #1976C5 / pressed #005BA1（白字对比度 5.9:1） |
| 中性色 | 带蓝调（#F3F5F9 / #E4E8F0 / #101828） | **纯中性灰**：页面 #F3F3F3、卡片白、线 #E5E5E5、正文 #1B1B1B |
| 渐变 | 标题、按钮、胶囊、统计卡上共 6 处渐变 | **全部改实色**——`AccentGradient` 等画刷键名保留、值换实色，引用方零改动 |
| 圆角 | 12 / 9 / 8 / 6 | **8 / 6 / 4**（卡片 8、按钮与输入 4、胶囊全圆），更贴近 Win11 控件语言 |
| 页面层级 | 标题栏 / 命令条 / 状态条三张白卡拼接 | **整窗一张 mica 浅灰表面**，仅内容列表卡浮起为白色，层级靠明度差 |
| 浮动选择条 | 深色面板 | **白色浮层**（Win11 浮出面板语言），阴影承担「浮」的表达，导出按钮保持实心蓝 |
| 大标题 | 渐变蓝字 | 中性深色，accent 只留给「主操作 + 勾选态」 |

工程上沿用既有的令牌契约：全部改动收敛在 `Theme/Tokens.xaml`（配色/圆角）+ `MainWindow.xaml` 三个表面 + `GradientText.cs` 一行取色，自绘控件（`StatCard` / `CountPill` / `CheckBoxEx` / `MiniProgress`）经由 `ThemeLookup` 自动继承新配色，零代码改动。

顺带新增 `tools/shot-window-pid.ps1`：按进程名定位窗口截图，避免应用标题与浏览器标签页撞车。

## 功能（与 2.18.1 相同）

- **扫描** `winget list`，按「软件 / 系统组件·运行库」分节展示，支持搜索、分组折叠、批量勾选
- **导出三种格式**（一套三个文件）：`apps.json`（winget import 标准清单）+ `恢复-*.bat`（GBK，双击批量重装）+ `无法自动重装清单-*.html`
- **元数据异步核查**：本地缓存 TTL 默认 90 天（`WPM_META_TTL_DAYS` 可调）
- **便携模式默认开启**：数据在 exe 同级 `Data\`，目录不可写时自动回退 `%LOCALAPPDATA%\WingetManager`

**定位是只导出、不导入**：本工具不会替你安装任何软件，安装动作只发生在恢复脚本由你亲手双击时。

## 已知局限

- 便携模式的数据在 `Data\`；若把 exe 单独拷到只读目录（如 `C:\Program Files`），数据会自动落到 `%LOCALAPPDATA%`。
- 纯视觉项（对话框首帧高度、无边框窗口最大化留边、字体回退观感）无法自动化，建议肉眼看一眼。
- 逻辑层未做 fuzz；`winget list` 的输出格式若大改，解析器需跟着调整（已有 `ParseByGaps` 兜底与 445 条断言护着）。
